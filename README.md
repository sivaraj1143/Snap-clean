# SnapClean Android project

SnapClean is a simple Android demo app with two review sections:
- Select friend categories to review before unfriending.
- Select chat categories to review before clearing/removing conversations.
- Review selections and open Snapchat Help.

## Important limitations
This demo does not connect to Snapchat, access a user's friend list or conversations, unfriend people, or delete chats. The selections are sample categories only. Actual changes must be performed through Snapchat's supported app features. Do not provide Snapchat passwords or session cookies to third-party apps.

## Build
1. Open the `SnapClean` folder in Android Studio.
2. Allow Gradle sync to finish.
3. Select **Build > Build APK(s)**.
4. The debug APK is typically created at `app/build/outputs/apk/debug/app-debug.apk`.

Requirements: Android Studio with a compatible Android SDK and Gradle setup.
